Structured numeric claims must exactly match deterministic metric values, units, true denominators and all contributing observations. Source receipt and scope admission occurs before response processing.

**Critical semantic limit:** source-reference existence and arithmetic consistency do not prove football entailment. Successful non-abstaining analyses return `accepted_for_offline_review`, require independent semantic review and have `feature_admission:false`. Free prose is not automatically certified. The four quantitative warrants are necessary directional-consistency conditions, not empirically learned effects. Context features require relevant source context but still cannot reach mathematics. Every usable level in the future mapping interface is null; it contains no rate/boost/coefficients or scoring-model call. Candidate categories remain traceable for later review and ablation design only.
