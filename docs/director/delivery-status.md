## Findings and changes

Both the source public renderer and generated staging renderer cleared or hid richer panels. They now render nine ordered analysis accordions and the compact hero, with source-backed values independent of whether an immutable pick exists. Issued selection probabilities and original 1X2 vectors retain their distinct meanings. Completed/live Scores routes use the same bounded presentation.

Synthetic history sentinel entries were replaced with native History API entries and bounded in-memory UI snapshots. Restoration preserves view, date/filter selection, ordering, row listeners, open state and scroll. Account/edition guards prevent restoring invalid snapshots. This is browser automation evidence, not physical Android acceptance.

The Analysis competition selector no longer applies the private domestic-history threshold to already-admitted public fixtures. No new international ingestion or forecasting was enabled.
